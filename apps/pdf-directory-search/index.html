PDF フォルダ検索

PDFを貯めているフォルダを選ぶと、ファイル名で絞り込んでブラウザのタブで開けます。ファイルは外部に送信されず、選んだフォルダの読み取りのみ行います。

お使いのブラウザはこの機能（File System Access API）に対応していません。Chrome または Edge でお試しください。

ブラウザの仕様上、フォルダ選択だけでは絶対パスを取得できません。ここにフルパス（エクスプローラーのアドレスバーからコピー）を入力すると、blobではなく file:/// のURLで開けるようになり、Geminiなど一部の拡張機能・AIツールからも読み込めるようになります。空欄なら従来通りblobで開きます。
